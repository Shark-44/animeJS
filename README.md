# animeJS

Une animation de météo du soleil a la pluie avec un rewind a tout instant.

Soleil, des premiers nuages, une animation de plus en plus de nuages avec un coté gris et enfin la pluie. Un bouton rewind qui peut intervenir a n'importe quel moment 

Mon code est brouillon intentionnellement pour montrer que j'ai travaillé par étapes et avec des erreurs. J'ai appris quelques tips.
